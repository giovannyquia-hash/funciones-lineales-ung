## Funcionalidades

- Buscador de competencias.
- Pregunta de ejemplo al pasar el cursor.
- Práctica con respuestas aleatorias y retroalimentación.
- Gráficas SVG de rectas, rectas verticales, segmentos, puntos y parábolas.
- Puntuación guardada en `localStorage`.
- Resumen de fórmulas: pendiente-intersección, pendiente entre dos puntos, punto-pendiente, rectas horizontales y verticales.
